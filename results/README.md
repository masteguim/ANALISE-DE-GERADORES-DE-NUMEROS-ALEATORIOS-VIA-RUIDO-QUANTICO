# Resultados

Esta pasta é destinada aos resultados consolidados derivados dos experimentos.

Os resultados principais do projeto são obtidos a partir dos dados brutos e dos arquivos de métricas publicados no repositório.

Entre os resultados analisados estão:

- proporção de bits 0 e 1;
- viés;
- entropia de Shannon;
- min-entropia empírica;
- autocorrelação;
- Runs Test;
- intervalos de confiança;
- resultados do condicionamento por von Neumann;
- resultados do condicionamento por SHA-256.

Os arquivos presentes nesta pasta devem corresponder apenas a resultados derivados, tabelas, resumos ou saídas consolidadas, preservando os dados brutos separadamente.
